# Инструкции проекта

## Проект и платформа

- Проект — прошивка BLDC-привода для робота SPbUnited; целевая конфигурация PlatformIO — `disco_b_g431b_esc1` (STM32G431B-ESC1, Arduino framework).
- Плата использует собственную таблицу выводов в `include/pinout.h`. Перед изменением выводов или периферии сверяйся с ней и конфигурацией платы.
- Сборка использует PlatformIO, локальные библиотеки в `lib/`, SimpleFOCDrivers `^1.0.9` и форк Arduino STM32 Core из Git по ветке `analogread`. Не обновляй платформу и библиотеки без необходимости.
- Подтверждённое номинальное напряжение питания платы и мотора — 24 В. Настройку PlatformIO `power.supply` нужно согласовать с этим значением, прежде чем полагаться на неё.

## Код и интерфейсы

- `src/main.cpp` содержит `setup()`/`loop()`. Аппаратная инициализация и управление мотором находятся в `src/hw/`; CAN — в `src/can/`; чтение ID — в `src/id/`; индикация — в `src/led/`; коды ошибок — в `src/error/`.
- Общая карта CAN-регистров и обработка протокола находятся в `include/CAN_Fuoco.h`; описание регистров — в `registers.csv`. Сохраняй их совместимость при изменениях интерфейса.
- Распиновку, параметры мотора, пороги защиты и преобразования показаний считай аппаратно значимыми. Не меняй их без подтверждённых требований и согласованных единиц измерения.
- `src/hw/hw.h` связывает мотор с `LowsideCurrentSense` (заданы шунт 0,003 Ом и коэффициент -9), но включает torque control в режиме напряжения. Задача current sense — запуск ОУ и достоверное измерение фазного тока; не включай замкнутое управление током без отдельного требования.
- Платформенная реализация B-G431B ESC1 находится в `lib/Simple FOC/src/current_sense/hardware_specific/stm32/b_g431/`. В ней параметры ADC и соответствие каналов DMA фазам являются частью одной конфигурации: сверяй их вместе при изменении.
- `motor_id == 0` включает отдельную ветвь управления в `loop()`. Учитывай её при изменении выбора ID, запуска мотора и поведения при ошибках.
- Сообщения CAN могут поступать во время работы контура FOC. Обеспечивай корректное ограничение данных по длине и безопасное состояние привода при ошибках; не блокируй основной контур ожиданием.
- Формат C++ задаёт корневой `.clang-format` (Google, Allman, отступ 4 пробела). Новые и изменённые C++ файлы форматируй `clang-format`.

## Сборка и проверки

- Сборка: `pio run -e disco_b_g431b_esc1`.
- Загрузка через настроенный ST-Link: `pio run -e disco_b_g431b_esc1 -t upload`.
- Последовательный монитор: `pio device monitor -e disco_b_g431b_esc1` (115200 бод).
- Каталог `test/` пока содержит только шаблонный README; перед использованием `pio test` добавь и настрой реальные тесты.
- Успешная сборка или загрузка не подтверждает безопасную работу мотора; аппаратную проверку описывай отдельно.
